# 🚀 DOCK: Universal Modular Hub for Mars Missions

> **“DOCK is a universal plug-and-play system that turns one smart device into many mission-critical tools — reducing complexity for future Mars explorers.”**

---

## 🧠 The Problem
Future space missions—especially those involving non-professional astronauts—require **simple, reliable, and multi-purpose hardware**. 

Currently, carrying separate standalone devices for sleep therapy, habitat safety, and environmental monitoring is inefficient. It increases **mass (launch cost)**, **power consumption**, and **technical complexity**. In the vacuum of space, every gram and every joule matters.

## 💡 The Solution: DOCK
**DOCK** is a universal modular docking system. It centralizes processing power into one "Smart Core" and uses lightweight, interchangeable modules to adapt to mission needs.

### 🧩 System Architecture

#### 1️⃣ The Main Dock (The Brain)
*   **Hardware:** ESP32, 0.96” OLED Display, 5 Navigation Buttons, 10-pin Universal Female Header.
*   **Intelligence:** Automatic Module Identification (AMI). The firmware detects the connected module and switches modes instantly without a reboot.

#### 2️⃣ Sleep Pod Module (Crew Rest & Mental Health)
*   **Hardware:** DHT22 (Temp/Hum), Active Buzzer.
*   **Logic:** Improves sleep quality in confined spaces via white noise generation and circadian rhythm monitoring.

#### 3️⃣ Habitat Safety Module (Environment Guard)
*   **Hardware:** MQ Gas Sensor, Vibration Sensor, LDR (Light).
*   **Logic:** Continuous passive monitoring for CO2 leaks or structural kinetic stress (Sandstorms), requiring zero crew interaction.

## 🌌 Why This Matters for Mars

| Mission Phase | DOCK Contribution |
| :--- | :--- |
| **Preparation** | Reduces device count and simplifies training for civilian explorers by using a unified interface. |
| **The Journey** | Saves critical power and mass; supports mental well-being via games and white noise in deep-space isolation. |
| **On Mars** | Adapts to habitat growth; provides autonomous early warning for lethal sandstorms and atmospheric leaks. |
